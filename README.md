# Primavera PM System

Oracle Primavera P6風デスクトップ専用プロジェクト管理システム

## 技術スタック
- **フロントエンド**: Electron + React + TypeScript
- **データベース**: SQLite
- **UI フレームワーク**: Material-UI
- **状態管理**: Redux Toolkit

## 開発状況
- ✅ Sprint 1: 基盤構築完了
- ✅ Sprint 2: WBS・タスク管理（部分完了）
- 🚧 Sprint 3: ガントチャート機能（開発中）

## セットアップ

```bash
npm install
npm run dev    # 開発サーバー起動
npm start      # Electronアプリ起動
```
