# プリマベーラ風プロジェクト管理システム要件仕様書

## 1. システム概要

### 1.1 プロジェクト名
**Primavera PM System** - Oracle Primavera P6風デスクトップ専用プロジェクト管理システム

### 1.2 目的
Oracle Primavera P6の機能性を維持しながら、UX/UIを大幅に改善したデスクトップ専用プロジェクト管理システムを開発する。

### 1.3 対象ユーザー
- プロジェクトマネージャー
- スケジュール管理者
- リソース管理者
- プロジェクトチームメンバー

## 2. 機能要件

### 2.1 プロジェクト管理機能
- プロジェクト作成・編集・削除
- プロジェクト設定管理
- 複数プロジェクトの統合表示

### 2.2 WBS（作業分解構造）管理機能
- 階層構造でのタスク管理
- ドラッグ&ドロップによる階層変更
- インライン編集機能
- タスクコード自動生成

### 2.3 ガントチャート機能
- 3階層タイムラインヘッダー（年・月・日）
- タスクバーの描画とドラッグ操作
- 休日表示と色分けシステム
- ズーム・スクロール機能
- クリティカルパス表示

### 2.4 CPMスケジューリング機能
- クリティカルパス計算
- フロート計算（Total Float, Free Float）
- 最早開始日・最遅終了日計算
- スケジュール更新機能

### 2.5 リソース管理機能
- リソース定義・管理
- リソース配分とレベリング
- 利用率グラフ表示
- リソースヒストグラム

### 2.6 進捗管理・EVM機能
- 進捗入力機能
- ベースライン管理
- EVM指標計算（PV, EV, AC, CPI, SPI）
- 進捗ダッシュボード

### 2.7 レポート・エクスポート機能
- Excel/CSVエクスポート
- PDF レポート生成
- カスタムレポート機能
- ダッシュボード表示

## 3. 技術要件

### 3.1 技術スタック
- **フロントエンド**: Electron + React + TypeScript
- **データベース**: SQLite（ローカルストレージ）
- **UI フレームワーク**: Material-UI
- **状態管理**: Redux Toolkit
- **ビルドツール**: Webpack

### 3.2 非機能要件
- **起動時間**: 3秒以内
- **大量データ処理**: 1000タスクで5秒以内
- **メモリ使用量**: 512MB以下
- **ガントチャート描画**: 2秒以内
